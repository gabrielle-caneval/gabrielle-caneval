# Hi, I'm Gabrielle Caneval

**AI Engineer | Generative & Agentic AI | Applied Research**

I design, build and evaluate systems using LLMs, RAG and multi-agent architectures. My background in biology and biotechnology informs an experimental approach to AI engineering, with experience in healthcare and an interest in applications across industries.

### Selected projects

- **[MedDiag IA](https://github.com/7gabrielle7/meddiag-ia-portfolio)**: an individual academic prototype combining a Next.js interface, a FastAPI backend and LangGraph orchestration. Two parallel LLM analyses feed an arbitration step, followed by a human review interaction in the interface. The repository includes a video of the real interface with simulated AI responses. No clinical validation is claimed.
- **[Science Feed](https://github.com/7gabrielle7/science-feed)**: a scientific discovery application using arXiv and Semantic Scholar, with authentication, interests, search and saved articles. Built with Next.js, TypeScript, Auth.js, Prisma and SQLite.
- **[TrainWeek](https://github.com/7gabrielle7/trainweek)**: a fitness application for workout programs, sessions and progress tracking, with local browser storage and an optional Groq-powered coach. Built with Next.js, TypeScript, Framer Motion and Recharts.
